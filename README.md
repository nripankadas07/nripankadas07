## Selected projects

- **[Trustline MCP](https://github.com/nripankadas07/trustline-mcp)** simulates tool-call policy and verifies audit records. [Offline demo](https://nripankadas07.github.io/trustline-mcp/). Experimental; it does not intercept or execute upstream tools.
- **[Grid Ops Arena](https://github.com/nripankadas07/grid-ops-arena)** replays seeded microgrid outages and reports reliability, cost, emissions, and safety. [Offline demo](https://nripankadas07.github.io/grid-ops-arena/).
- **[Value Density Lab](https://github.com/nripankadas07/value-density-lab)** compares product outcomes against time, friction, regret, and harm. [Offline demo](https://nripankadas07.github.io/value-density-lab/).
- **[PatchGym](https://github.com/nripankadas07/patchgym)** turns Git history into local coding-agent tasks with hidden tests and oracle patches.
- **[RunMirror](https://github.com/nripankadas07/runmirror)** records deterministic cassettes for replaying agent calls and tool behavior.
- **[Climate Evidence Bench](https://github.com/nripankadas07/climate-evidence-bench)** checks numerical, unit, temporal, geographic, provenance, and citation accuracy in climate answers.

## Evidence, not theatre

Trustline MCP is an experimental policy lab. Its runnable examples and
transport tests demonstrate local simulation and audit verification, not a
production policy proxy. The release audit below is a dated snapshot; it does
not establish the current security status of every repository or open PR.

The August 16, 2026 release gate verified **10 public v0.1.1 releases, 1,020
source and extracted-package test executions, 26 live release assets, three
current-main proof sites, and zero open CodeQL, Dependabot, or secret-scanning
alerts at audit time**.

- [Post-release stress and security audit](docs/POST_RELEASE_STRESS_AUDIT_2026-08-16.md)
- [Reliable AI release architecture](docs/RELIABLE_AI_RELEASE.md)
- [Deep profile and landscape audit](docs/DEEP_AUDIT_2026-08-16.md)

My working rules are simple: high-stakes automation needs human takeover;
evaluation must leave evidence; composite scores must expose their parts; and
benchmarks must state their limitations.
