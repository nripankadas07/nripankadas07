### Open-source utility library

I'm building a **portfolio of small, polished, zero-dependency libraries** &mdash; each spec'd, test-driven, self-reviewed, and shipped with a complete README. Current count: **34+ utilities** spanning data structures, parsers, formatters, and CLI helpers, with target line coverage at **100%**.

A few that stand out:
- [`bitvec`](https://github.com/nripankadas07/bitvec) &mdash; packed bit-vector with set ops and slicing
- [`crontab-lite`](https://github.com/nripankadas07/crontab-lite) &mdash; cron expression evaluator with `next_fire` / `prev_fire`
- [`rangeset`](https://github.com/nripankadas07/rangeset) &mdash; non-overlapping integer-range set algebra
- [`trie`](https://github.com/nripankadas07/trie) &mdash; prefix tree with autocomplete
- [`levendist`](https://github.com/nripankadas07/levendist) &mdash; Levenshtein, Damerau-Levenshtein, Jaro, Jaro-Winkler, LCS in one place
- [`globmatch`](https://github.com/nripankadas07/globmatch) &mdash; fnmatch superset with extglob, POSIX classes, and `**` globstar
- [`tsparser`](https://github.com/nripankadas07/tsparser) · [`base62-ts`](https://github.com/nripankadas07/base62-ts) &mdash; tokenizer/parser and Base62 codec for TypeScript

### How I build

I prefer software that proves itself in use: clear interfaces, direct documentation, small testable modules, and graceful failure paths. My goal is not just to make AI demos that look impressive on stage &mdash; it is to turn intelligence into dependable product behavior.

Every repository above follows the same five-axis review: **correctness · security · readability · performance · maintainability**. Functions are short, tests are first-class, errors are typed, and dependencies are minimal. If you can't read it end-to-end in a single sitting, it's too big.
