## Limits and evidence

- **notebook-state-check:** Saved counts do not prove reproducibility, freshness, causality or correctness. No kernel execution or secret detection. nbformat 4 subset, maximum 10 MB / 10,000 cells; cell positions are zero based. See [research](https://github.com/nripankadas07/notebook-state-check/blob/main/RESEARCH.md), [local validation record](https://github.com/nripankadas07/notebook-state-check/blob/main/VALIDATION.md), and [runnable demo](https://github.com/nripankadas07/notebook-state-check/blob/main/demo.py).
- **redirect-graph:** Exact local paths only, case sensitive and percent encodings unchanged. No pattern, query, fragment, external URLs or web reachability checks. 2 MB / 10,000 rules; graph traversal worst case quadratic. Terminals are user supplied, not verified deployments. See [research](https://github.com/nripankadas07/redirect-graph/blob/main/RESEARCH.md), [local validation record](https://github.com/nripankadas07/redirect-graph/blob/main/VALIDATION.md), and [runnable demo](https://github.com/nripankadas07/redirect-graph/blob/main/demo.py).
- **lfs-handoff:** Audits exported pointer files, not Git history or attribute rules. Smudged working trees may contain no pointers. No network, fetch, push, server existence claim or repair. Extensions unsupported; symlink input files/directories skipped. Stable trusted local trees only, no protection from concurrent file replacement. Hash work grows with object bytes; 100,000 input file bound. See [research](https://github.com/nripankadas07/lfs-handoff/blob/main/RESEARCH.md), [local validation record](https://github.com/nripankadas07/lfs-handoff/blob/main/VALIDATION.md), and [runnable demo](https://github.com/nripankadas07/lfs-handoff/blob/main/demo.py).
- **jsonl-seek:** Safety-first lookup revalidates the whole source, including offsets; it is O(file size) and is not a speed claim. Offset storage is O(records). No compressed files, blank lines, JSON-LD or concurrent file replacement guarantee. One MiB per line / one million records. Index creation refuses existing output files. See [research](https://github.com/nripankadas07/jsonl-seek/blob/main/RESEARCH.md), [local validation record](https://github.com/nripankadas07/jsonl-seek/blob/main/VALIDATION.md), and [runnable demo](https://github.com/nripankadas07/jsonl-seek/blob/main/demo.py).
- **sourcemap-trace:** Flat v3 maps only, no indexed sections, map composition, sourceRoot resolution or code snippets. Returned source labels are raw map entries, not fetched/resolved files. No precision interpolation inside a mapping span. Duplicate generated columns rejected. 10 MB JSON / 5 million mapping characters. Linux tested; no telemetry or runtime dependencies. See [research](https://github.com/nripankadas07/sourcemap-trace/blob/main/RESEARCH.md), [local validation record](https://github.com/nripankadas07/sourcemap-trace/blob/main/VALIDATION.md), and [runnable demo](https://github.com/nripankadas07/sourcemap-trace/blob/main/demo.py).

Demand is inferred, not verified user requests. Each research artifact records dated star-sorted queries, relevant comparables, maintenance and licensing limitations. No competitor superiority, timed performance, adoption or full standards-conformance claim. Linux was exercised; Windows/macOS and production workloads remain unverified.
