## Validation and installation

56 core unit tests, compilation, five clean virtual-environment source installs (wheel builds) and 15 installed-CLI cases passed before publication. Each remote default-head CI matrix passed on Python 3.10, 3.12 and 3.14: 15 successful jobs total. Every job runs the same acceptance, findings and malformed-input installed-CLI checks outside the source directory, plus the synthetic demo. All 83 source, documentation and fixture blobs match the prepared files exactly.

Each README supplies the documented `git clone`, virtual environment, `pip install .`, CLI command and `python demo.py` path. There are no runtime dependencies or account/API-key requirements; installation may download setuptools from PyPI. No registry package was published. Install and demo paths are runnable repository content; these are command-line tools without hosted demo sites.

- **csp-fallback-diff**: Per-policy representation diff; not browser enforcement or a security verdict. [Detailed limits](https://github.com/nripankadas07/csp-fallback-diff/blob/6fc2423dc8303fd4c0975d30d07106c955098fbc/README.md), [user brief and research](https://github.com/nripankadas07/csp-fallback-diff/blob/6fc2423dc8303fd4c0975d30d07106c955098fbc/RESEARCH.md), [validation scope](https://github.com/nripankadas07/csp-fallback-diff/blob/6fc2423dc8303fd4c0975d30d07106c955098fbc/VALIDATION.md).
