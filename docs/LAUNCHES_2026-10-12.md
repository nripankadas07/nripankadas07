## Confirmed error repaired

At HTTP Range Witness commit `536cd1d5f7393e5ad131b6303eb9b9437aa7c5aa`, `BYTES=0-9` was rejected because the prefix comparison required lowercase. [RFC 9110 §14.1](https://www.rfc-editor.org/rfc/rfc9110.html#section-14.1) defines range-unit names as case-insensitive. [PR #2](https://github.com/nripankadas07/http-range-witness/pull/2) changes only the prefix comparison and adds uppercase/mixed-case equivalence checks for multiple ranges. 15 tests, compilation, wheel build and clean installation passed locally; six branch/PR matrix checks and all three merged default-head checks passed. The final head is `36fbb1da74db1dc338f4baf56213caaab20a4e38`. No tests, scanners or thresholds were disabled. This repair is maintenance and does not count as another launch.
