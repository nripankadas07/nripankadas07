## Confirmed compatibility error repaired

SQLite CI initially failed on Python 3.10 at PR head `2f730b30dce0f9836f84f47f1e79baff31e8005c`: the existing multi-statement rejection test reproduced `sqlite3.Warning`, which was not a subclass of the expected DatabaseError contract or the CLI catch. The implementation now normalizes that rejected input to DatabaseError. The original rejection test was preserved, local packaging/install checks reran successfully, and repaired PR head `ed19fc0cbb643d557b2aec94d42b5c7545ee3efd` plus the final main pass all three Python versions. [Failing evidence](https://github.com/nripankadas07/sqlite-plan-witness/actions/runs/38031783227/job/114154070715); [repair commit](https://github.com/nripankadas07/sqlite-plan-witness/commit/ed19fc0cbb643d557b2aec94d42b5c7545ee3efd). No checks were disabled or expectations weakened.
