# Help test three independent projects

Choose one project that matches your work. Each has a short browser review, a
local experiment, and a feedback form. Specific criticism and blocked attempts
are welcome. No star, endorsement, or prior relationship is needed.

| Project | Who it is for | First task | Start / feedback |
| --- | --- | --- | --- |
| Trustline MCP | MCP developers and tool-permission reviewers | Explain an allow, deny, and approval decision; locally change a quota and check your prediction | [Try it](https://github.com/nripankadas07/trustline-mcp/blob/main/docs/USER_PILOT.md) · [Feedback](https://github.com/nripankadas07/trustline-mcp/issues/new?template=user_feedback.yml) |
| Grid Ops Arena | Energy modelling students, educators, and Python developers | Explain a constraint violation; locally compare dispatch policies and battery limits | [Try it](https://github.com/nripankadas07/grid-ops-arena/blob/main/docs/USER_PILOT.md) · [Feedback](https://github.com/nripankadas07/grid-ops-arena/issues/new?template=user_feedback.yml) |
| Value Density Lab | Product managers, UX researchers, and product analysts | Challenge a scoring assumption; locally report on a workflow you understand | [Try it](https://github.com/nripankadas07/value-density-lab/blob/main/docs/USER_PILOT.md) · [Feedback](https://github.com/nripankadas07/value-density-lab/issues/new?template=user_feedback.yml) |

Browser reviews take roughly five minutes; local tasks roughly fifteen minutes
plus setup. These are estimates. The browser demos display saved synthetic
reports; they do not run live inputs. You can report where you stopped.

Tell me what you tried, whether you completed it, and one result or confusing
point. If you return after an improvement, add a dated comment to the same issue
with your new task and result. You can decline follow-up and quotation separately.

**Issues and your GitHub identity are public.** Keep secrets, raw personal
records, and private employer or customer data out of feedback. Use synthetic
reproductions. Security reports should use the relevant repository's security
reporting instructions.

These projects are experimental. Synthetic examples establish software behavior,
not production safety, grid performance, or causal product impact. Each pilot
links to the project's limitations and AI-assistance disclosure remains in its
repository.
