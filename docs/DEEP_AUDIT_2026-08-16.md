# Deep GitHub and portfolio audit — August 16, 2026

## Decision

The profile did not need more generic inventory. It needed a defensible category,
visible proof, distribution, and a reason for outside engineers to participate.

The resulting direction is **reliable AI for high-stakes decisions**: agent
reliability infrastructure tested against deterministic energy, climate, carbon
risk, and product-measurement workloads.

## Profile snapshot before this release

Public GitHub data and authenticated contribution metadata showed:

- 118 public repositories: 117 active and one archived;
- 115 repositories created between March and May 2026;
- 94 Python repositories, 23 TypeScript repositories, and one repository with no detected language;
- one total star, zero forks, and one follower;
- 1,672 contributions in the prior year, concentrated into 41 active days;
- zero issues, pull requests, or reviews contributed to repositories owned by others;
- a median repository size of 25 KB, 14 commits, and three code files;
- 93 repositories with no GitHub release;
- only one real hosted product demo, SpecForge;
- strong hygiene across active repositories: README, license, CI, packaging, security/contribution material, and templates.

The contradiction was clear: the profile demonstrated automation and breadth,
but almost no adoption, outside collaboration, release continuity, or visual
product proof. More small utilities would amplify that weakness.

The profile README also repeated the same conversion path in several sections,
while the six pinned repositories did not match the stated flagship stack. It
has been shortened around proof paths and one technical narrative.

## What current high-signal projects teach

The repositories earning durable attention share a few patterns:

- a narrow promise that can be understood in one sentence;
- a working product or binary, not a tutorial notebook;
- a visible 30–90 second proof;
- measurable performance, safety, or quality claims with disclosed methods;
- integrations with tools developers already use;
- frequent releases and an external contributor loop.

Examples include [uv](https://github.com/astral-sh/uv),
[Spec Kit](https://github.com/github/spec-kit),
[Browser Use](https://github.com/browser-use/browser-use),
[Graphify](https://github.com/Graphify-Labs/graphify),
[RTK](https://github.com/rtk-ai/rtk), and
[Headroom](https://github.com/headroomlabs-ai/headroom). Their raw star counts
are not the lesson; replacement-level utility, distribution, proof, and repeated
maintenance are.

## Integrity guardrails

- No purchased, exchanged, or automated stars.
- No copied code, branding, README text, or unsupported feature claims from popular repositories.
- No employer data, internal methodology, branding, or implied endorsement.
- Applied fixtures are synthetic unless a pinned public source and digest are provided.
- Composite scores expose components, assumptions, uncertainty, and limitations.
- AI-assisted implementation is disclosed; generated demo results are not presented as adoption.

This matters because a 2026 empirical study identified millions of suspected
fake GitHub stars and found that artificial promotion is a poor long-term signal.
See the [ICSE 2026 StarScout paper](https://cmustrudel.github.io/papers/icse2026fakestars.pdf)
and [replication materials](https://github.com/hehao98/StarScout). The study
identified 6.0 million suspected fake stars while explicitly acknowledging
possible false positives; no allegation is made about any repository named in
this audit.

## What success means next

Repository count and raw stars are not operating metrics. Track:

1. independent successful demo runs;
2. issue-to-resolution time and reproducible outside bug reports;
3. outside contributors and merged upstream integrations;
4. release cadence and upgrade adoption;
5. benchmark replications and cited artifacts;
6. clicks from technical launch material to a completed proof path;
7. repeat users, not launch-day impressions alone.

The profile should earn attention by being useful and falsifiable. Stars, if they
come, should be the exhaust of that process.
