# Profile editing guidance

For README and portfolio documentation updates:

- Keep Trustline MCP, Grid Ops Arena, and Value Density Lab as the three leading
  case studies. Preserve their case-study, live-demo, and repository links.
- Keep PatchGym, RunMirror, and Climate Evidence Bench available in the compact
  supporting-project section. Use the chronological project index for the rest.
- Put daily launch receipts and long audit history in linked documents rather
  than expanding the main README with a growing list of dates.
- Ground results in inspectable artifacts. Label synthetic examples beside their
  metrics; never imply they establish customer adoption or production impact.
- Preserve personal context, AI-assistance disclosures, explicit limitations,
  and meaningful health-review links. Refresh screenshots and commit-linked
  evidence only when the underlying project changes.
- Run the existing documentation link check and applicable CI before merging.

These conventions preserve the user's requested three-case-study profile layout.
